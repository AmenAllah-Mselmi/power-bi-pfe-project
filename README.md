# power-bi-pfe-project
Solution CRM intelligente avec Next.js et NestJS, incluant un moteur de Lead Scoring par IA et un dashboard Power BI avancé. Pilotez votre performance commerciale en temps réel grâce à l'analyse de pipeline, le suivi des conversions et des KPIs stratégiques (DAX) pour transformer vos données en décisions concrètes.
